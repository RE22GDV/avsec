# Сирі результати, які увійшли до звіту

Курована добірка артефактів фактично виконаних прогонів. Повні прогони
(включно з усіма зображеннями і `frames.jsonl`) не комітяться — вони
відтворюються командами з кореневого README.

| Файл | Що це |
| --- | --- |
| `comparison_moderate/` | порівняння B0–B4 і P на каналі `moderate`, 21 послідовність × 3 реалізації |
| `comparison_bursty/` | **вирішальний прогін гіпотези** на каналі `bursty`, 21 послідовність × 5 реалізацій |
| `sweeps.csv` / `.json` | якість і покриття залежно від профілю каналу (clean…harsh) |
| `ablations.csv` / `.json` | абляції запропонованої конфігурації, по одному фактору за раз |
| `attacks.csv` / `.json` | атаки на B1/B2 і 15 перевірок протоколу AEAD |
| `similarity_2021_metric.csv` | «схожість» у сенсі статті 2021 (кореляція, %) для seed 44257/1234/1111 |
| `budget.json` | точний облік місткості каналу, накладних витрат і модельної затримки |
| `cvbs_level_b.json` | наскрізний прогін через модель CVBS 625/50 (рівень B) |
| `tuning_families.json` | добір параметрів окремо для родини B4 і родини P, однакові калібрувальні дані |
| `tuning_candidates.csv` | усі кандидати пошуку з причинами відхилення |
| `resolved_config_moderate.yaml` | повна розв'язана конфігурація прогону |
| `figures/` | оглядова панель, графіки залежності від каналу, приклади кадрів і атаки |
| `report_moderate.md`, `report_bursty.md` | згенеровані звіти з позначками `[ЗАПУСК]` / `[МОДЕЛЬ]` / `[НЕ ВИКОНАНО]` |

**SYNTHETIC DATA.** Усі послідовності процедурно згенеровані. Жодного вимірювання
на фізичному обладнанні тут немає.

Кожен `*.json` містить блок `record` із конфігурацією, версіями залежностей,
характеристиками платформи, hash вхідних даних і лічильниками успішних /
невдалих / пропущених випробувань. Секретні ключі не зберігаються: усі прогони
виконані в режимі `key_mode: lab`.

Тлумачення чисел і застереження — у [../docs/results.md](../docs/results.md).
