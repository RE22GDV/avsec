# Курована добірка результатів

Тут лежить те, чим підкріплене кожне опубліковане число, у формі, придатній для
перевірки без повторного запуску. Повні прогони (`runs/`, ~240 МБ покадрових
рядків і стану завдань) не комітяться — вони відтворюються командами з
кореневого README.

## `main/` — поточний прогін

Усе походить з **одного** `run_id`; він записаний у `main/run_manifest.json`
разом із commit, конфігурацією, seed-ами й планом. `main/CURATION.json` перелічує,
що саме скопійовано.

### Сирі таблиці

| Файл | Що це |
| --- | --- |

| `channel_traces.jsonl` | кожна реалізація каналу: як її відтворити і **які завдання її поділяли** |
| `frames.csv` | покадрові метрики (проріджено — див. `.README` поряд) |
| `units.csv` | статуси одиниць за кадр |
| `codewords.csv`, `joint_loss.csv`, `placement_geometry.csv` | E05: пошкодження RS-слів і спільні втрати описів |
| `timings.csv`, `scaling.csv` | E09: wall-clock за етапами і за роздільністю |
| `budgets.csv`, `budgets.json` | місткість, накладні витрати, подієва затримка, три величини пам'яті |

| `paired_effects.csv` | усі парні порівняння: ефект, CI, спосіб агрегування, поправка Holm |

Три формати одного рисунка — це **один** результат, а не три.

### Як перевірити число зі звіту

```bash
avsec analyze --input results/main          # перерахує ефекти з тих самих таблиць
python scripts/publish.py results/main      # перегенерує docs/results.md
```

Обидві команди читають лише те, що лежить тут, і нічого не запускають.

## `_historical/` — застарілі результати

Прогони до впровадження єдиного матричного runner-а (F17), подієвої моделі часу
(F16) і генерації документації з одного `run_id` (F18). **Ці числа не актуальні
й не змішуються з поточними**; пояснення у
[../docs/historical_results.md](../docs/historical_results.md).

Найважливіша змістовна зміна: перевага `P` над `B4` виявилася **залежною від
каналу**. Попередній звіт вимірював один канал і показував лише виграш; поточний
прогін показує і виграш на `bursty`, і програш на `clean`/`mild`.

## Застереження, які діють для всього вмісту цієї теки

* **SYNTHETIC DATA.** Усі 34 кліпи процедурно згенеровані. Жодного кадру з
  реальної камери.
* **Апаратних вимірювань немає** (E11 не виконано). Затримка, пропускна
  здатність і пам'ять — величини моделі.
* Канал — програмна модель рівнів A і B. Однакова назва профілю на двох рівнях
  не означає однаковий канал.
* Методи, позначені `*` у таблицях, нічого не автентифікують: їхнє «покриття» —
  це частка показаної картинки, а не перевірених даних.
