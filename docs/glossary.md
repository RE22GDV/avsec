Правило вживання: у пояснювальному тексті використовується повний український
термін, скорочення вводиться в дужках при першій появі в документі.
Програмні ідентифікатори (`psnr_full`, `deadline_miss`, `B4t`) наводяться
точно так, як у коді й таблицях, і не перекладаються.

## 1. Позначення методів

Позначення відповідають ключам у `summary.csv`, `operability.csv` та решті
таблиць прогону.

| Позначення | Повна назва | На яке питання відповідає ця схема |
| --- | --- | --- |
| `B0a` | аналогове передавання без захисту | верхня межа якості за відсутності будь-якої обробки |
| `B0a-R` | те саме з повторним передаванням | чи достатньо простого повтору кадру |
| `B0d` | цифрове передавання без захисту | вартість цифрового транспорту без криптографії |
| `B1` | реконструкція схеми ISITIA 2021: перестановка блоків, керована регістром зсуву | об'єкт відтворення й криптоаналізу |
| `B2` | та сама перестановка з криптографічним генератором, щокадрово | чи достатньо замінити генератор |
| `B2s` | перестановка блоків разом із ключовою заміною значень пікселів | що дає поєднання двох примітивів і скільки воно коштує в каналі |
| `B3` | автентифіковане шифрування всього кадру | вартість переходу до стандартної криптографії |
| `B4` | автентифіковане шифрування посегментно | відновлення доступності після сегментації |
| `B4t` | `B4` з параметрами транспорту схеми `P`, без MDC і BAWP | контрольна схема, яка відокремлює внесок транспорту від внеску механізмів |
| `P` | запропонована схема: `B4t` разом із MDC і BAWP | предмет заявки на новизну |

## 2. Скорочення

| Скорочення | Повний термін | Пояснення |
| --- | --- | --- |
| AEAD | автентифіковане шифрування з асоційованими даними (*authenticated encryption with associated data*) | шифрування, що водночас підтверджує цілісність шифротексту й відкритих полів заголовка |
| LFSR | регістр зсуву з лінійним зворотним зв'язком (*linear feedback shift register*) | генератор псевдовипадкової послідовності, ужитий у схемі 2021 року |
| FEC | завадостійке кодування (*forward error correction*) | тут — коди Ріда — Соломона над байтами кодового слова |
| RS | Рід — Соломон | конкретний код, ужитий для FEC |
| MDC | множинний опис (*multiple description coding*) | кодування кадру двома незалежними описами, кожен з яких сам дає прийнятне зображення |
| BAWP | розміщення з урахуванням пакетних пошкоджень (*burst-aware placement*) | правило розкладання одиниць у растрі |
| CSPRNG | криптографічно стійкий генератор псевдовипадкових чисел | заміна LFSR у схемі `B2` |
| DCT | дискретне косинусне перетворення | основа кодека зображення |
| PSNR | пікове відношення сигналу до шуму | метрика якості відновленого кадру |
| CVBS | композитний відеосигнал (*composite video baseband signal*) | сигнал на інтерфейсі аналогового тракту |
| TOFU | довіра за першим використанням (*trust on first use*) | режим приймача без збереженого реєстру сеансів |
| TOST | два односторонні критерії (*two one-sided tests*) | процедура перевірки еквівалентності в межах оголошеної межі |
| в. п. | відсоткові пункти | різниця двох величин, виражених у відсотках |

## 3. Терміни предметної області

| Термін | Визначення |
| --- | --- |
| Скремблювання перестановкою | перестановка прямокутних фрагментів кадру без зміни значень пікселів |
| Заміна (підстановка) | заміна кожного значення пікселя за бієктивною таблицею; у термінах Шеннона — заплутування |
| Таблиця замін (S-box) | бієкція `0…255 → 0…255`, виведена з ключа. Обернена таблиця (`S-box⁻¹`) відновлює вихідне значення точно |
| Розсіювання і заплутування | дві властивості за Шенноном: перше розподіляє інформацію по кадру (перестановка), друге руйнує зв'язок значення зі змістом (заміна) |
| Підсилення похибки | зростання похибки після оберненої таблиці: заміна не зберігає близькості значень, тому похибка в один рівень стає похибкою близько 85 рівнів |
| Початковий стан регістра | значення, яким ініціалізується LFSR (у коді — `LFSRConfig.seed`). **Не** є секретним ключем |
| Початкове значення генератора експерименту | значення, яким ініціалізується генератор псевдовипадкових чисел прогону (`seed`, `channel_seed`, `crypto_seed`) |
| Пакетне пошкодження | послідовна ділянка сигналу, спотворена одним завадним подієм. Не слід змішувати з транспортним пакетом |
| Одиниця транспорту | ділянка корисних даних із власним заголовком і власною міткою автентичності |
| Кодове слово | блок Ріда — Соломона зі своїм бюджетом виправлення; одиниця складається з кількох кодових слів |
| Витік структури | відновлення локальних сусідств фрагментів без відновлення їхніх абсолютних координат |
| Показане зображення | кадр, фактично виведений глядачеві, включно з ділянками попереднього кадру та інтерполяцією |
| Момент показу | запланований момент виведення кадру; рядок результату пишеться для кожного такого моменту, а не лише для успішних |
| Одиниця незалежності | рівень, за яким виконується перевибірка в bootstrap: сцена або вихідний запис |

## 4. Метрики

| Ідентифікатор | Визначення | Межа тлумачення |
| --- | --- | --- |
| `psnr_full` | PSNR по всьому кадру, усереднений **лише за успішними передаваннями** (`status == "ok"`) | умовна величина; не характеризує якість на всіх моментах показу |
| `psnr_displayed` | PSNR показаного зображення за всіма моментами показу | враховує ділянки попереднього кадру та інтерполяцію |
| `availability` | частка моментів показу, для яких отримано поточне зображення | рахується за всіма запланованими моментами |
| `coverage` | частка пікселів кадру, отриманих з одиниць, що пройшли перевірку AEAD | для схем без автентифікації значення 1 означає лише факт виведення зображення |
| `operable_fraction` | частка моментів показу, що задовольняють робочий критерій (`coverage >= 0,9` і `psnr_full >= 20` дБ) | критерій є інженерною вимогою цього дослідження, а не галузевим стандартом |
| `direct_accuracy` | частка фрагментів, розміщених атакою у правильних абсолютних позиціях | критерій успішного відновлення перестановки |
| `neighbour_accuracy` | частка суміжних пар, які були суміжними у вихідному кадрі | показник витоку структури |

## 5. Статистичні позначення

| Позначення | Значення |
| --- | --- |
| CI | довірчий інтервал. **Не** слід змішувати зі скороченням неперервної інтеграції, яке в цьому репозиторії позначається «GitHub Actions» |
| Holm | низхідна процедура корекції множинних порівнянь у межах наперед оголошеної сім'ї |
| Bootstrap | кластерна перевибірка за оголошеною одиницею незалежності, 10 000 перевибірок, фіксоване початкове значення генератора |
| `p_raw` | p-значення без корекції множинності |
| `p_holm` | p-значення після корекції Holm у межах оголошеної сім'ї |
| Еквівалентність | висновок TOST у межах ±0,5 дБ. Відсутність значущої різниці **не** є доказом рівності |

## 6. Позначення в таблицях і прогонах

| Позначення | Значення |
| --- | --- |
| `run_id` | ідентифікатор експериментального прогону, записаний у `run_manifest.json` |
| Коміт Git | версія програмного коду, за якої отримано результат; наводиться скороченим хешем |
| `clean`, `mild`, `moderate`, `bursty`, `harsh` | профілі каналу за зростанням тяжкості умов. Профілі **не** усереднюються між собою |
| `calibration`, `validation`, `test` | калібрувальна, валідаційна та тестова частини набору даних; поділ виконано за вихідним записом |
| `capacity`, `no_sync`, `deadline_miss`, `exception`, `skipped` | категорії відмов у `failures.csv`. Тлумачення `deadline_miss` обмежене: див. [limitations.md](limitations.md) |
| `[Л]`, `[Р]`, `[О]` | скорочені позначення прогонів-джерел у [reconstruction_2021.md](reconstruction_2021.md); легенда наведена в тому самому документі |
